快速找到 Android 应用的签名信息。

KeyStoreViewer 帮助开发者查看已安装应用与 APK 文件的签名证书，获取 MD5、SHA-1、SHA-256 证书指纹及公钥信息，无需翻找命令行输出。

主要功能
• 查看已安装应用的签名信息。
• 打开 APK 文件，读取其中的签名证书。
• 查看 MD5、SHA-1、SHA-256 证书指纹。
• 查看公钥信息，包括 RSA 公钥的模数。
• 复制指纹和公钥数值，或分享签名详情。

适用场景
• 查找 API 或第三方 SDK 配置所需的证书指纹。
• 获取应用备案所需的签名与公钥信息。
• 排查调试版与发布版之间的签名差异。

证书指纹用于识别签名证书，并非 APK 文件的校验值；签名一致也不代表应用一定安全。
